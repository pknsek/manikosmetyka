# Manikosmetyka — strona salonu

Statyczna strona salonu kosmetycznego Manikosmetyka (ul. Ligonia 8, Czerwionka-Leszczyny).

- `index.html` — strona główna, podstrony w osobnych plikach `.html`
- `site.css` — wspólne style
- `img/` — zdjęcia (obecnie zastępcze, do podmiany na zdjęcia z salonu)

Podgląd lokalny: `python3 -m http.server 8000`, potem http://localhost:8000
